시작하기휴대폰개인정보업데이트자주 묻는 질문제보 게시판

시작하기 (5분)

  1. 안내받은 원본 시트 링크를 열고 사본 만들기를 누르세요. 내 드라이브에 내 시트가 생겨요.
  2. 사본을 열면 위쪽 메뉴에 ✅ 내 업무가 생겨요. 처음 한 번은 ⚙️ 처음 설정을 누르세요.
  3. 권한 승인 화면이 나오면 내 계정을 고르고 허용을 누르세요. (아래 "확인하지 않은 앱" 경고를 먼저 읽어 보세요)
  4. 📱 휴대폰·웹 화면 링크를 누르면 설정 마법사가 웹 화면을 켜는 방법을 단계별로 안내해 드려요.
시트에서 바로 써도 되고, 웹 화면(휴대폰·PC)에서 써도 돼요. 둘은 같은 시트를 보고 있어요.

휴대폰에서 쓰기

  1. 시트 메뉴 📱 휴대폰·웹 화면 링크에서 내 링크를 복사해 휴대폰으로 보내세요. (나에게 카톡·메일)
  2. 휴대폰 브라우저(크롬·사파리)로 한 번 열면 그 브라우저가 기억해요.
  3. 홈 화면에 추가를 하면 앱처럼 쓸 수 있어요. (사파리: 공유 ▸ 홈 화면에 추가 / 크롬: ⋮ ▸ 홈 화면에 추가)
구글 시트 앱에서는 버튼과 메뉴가 동작하지 않아요. 휴대폰에서는 꼭 웹 화면 링크로 쓰세요.

개인정보 안내

  • 내 할 일은 내 구글 시트에만 저장돼요. 키트를 만든 사람을 포함해 누구도 내 시트를 볼 수 없어요. 별도 서버도 없어요.
  • 코드는 내 구글 계정 안에서, 내 권한으로 실행돼요. 승인하는 권한은 이 시트 읽기·쓰기, 나에게 메일 보내기(주간 정리·아침 브리핑), 구글 캘린더 일정 보기·시간표 넣기, 알림 예약이에요.
  • 이 웹 페이지는 화면(디자인)만 보여 줘요. 내 데이터는 내 브라우저에서 내 구글 계정으로 바로 오가고, 이 페이지에는 저장되지 않아요.
  • 내 링크는 열쇠예요. 링크 끝의 #api=…&k=…를 가진 사람은 내 할 일을 볼 수 있어요. 다른 사람에게 보내지 마세요.
  • 링크가 퍼졌다면 시트 메뉴 🔑 휴대폰 링크 새로 만들기를 누르세요. 예전 링크는 바로 막혀요.
  • 그만 쓰려면 시트를 지우면 끝이에요. 승인한 권한은 구글 계정 ▸ 보안 ▸ 서드파티 앱에서 해제할 수 있어요.

자주 묻는 질문

"Google에서 확인하지 않은 앱" 경고가 떠요

내 시트에 붙은 코드를 처음 실행할 때 나오는 구글의 기본 경고예요. 코드 주인이 바로 나 자신이라 구글 심사를 거치지 않았다는 뜻이에요. 고급 ▸ (안전하지 않은 페이지로) 이동 ▸ 허용을 누르면 돼요. 내 데이터는 내 계정 밖으로 나가지 않아요.

휴대폰에서 링크가 안 열리거나 "파일을 열 수 없다"고 나와요

휴대폰에 구글 계정이 여러 개 로그인돼 있으면 생기는 구글 쪽 문제예요. 이 페이지의 링크(…github.io/…#api=…)로 열면 계정과 상관없이 열려요. 시트 메뉴에서 링크를 다시 받아 보세요.

시트에서 직접 고쳐도 되나요?

네. 할 일을 추가·수정하거나 열 순서를 바꾸고 내 열을 추가해도 돼요. 키트는 열을 머리글 이름으로 찾아요. 단, ID 열의 값은 지우지 마세요.

캘린더 일정이 안 보여요

웹 화면 ▸ 더보기 ▸ 보이는 캘린더에서 보고 싶은 캘린더를 켜세요. 처음에는 기본 캘린더만 보여요. 회사 계정 캘린더는 내 구글 계정에 공유돼 있어야 보여요.

시간표를 캘린더에 넣으면 어떻게 되나요?

오늘 할 일이 기본 캘린더의 빈 시간에 ▶ 표시 일정으로 들어가요. 다시 넣으면 예전 것은 지우고 새로 넣어서 겹치지 않아요. 키트가 넣은 일정만 지우고, 내가 만든 일정은 건드리지 않아요.

실수로 지웠어요

완료·삭제 직후에는 아래쪽 되돌리기를 누르세요. 시간이 지났다면 시트에서 파일 ▸ 버전 기록으로 예전 상태를 볼 수 있어요. 삭제한 일은 상태가 '버림'으로 남아 있어 시트에서 다시 바꿀 수도 있어요.

주간 정리 메일이 안 와요

웹 화면 ▸ 더보기 ▸ 알림에서 주간 정리 메일을 켜세요. 금요일 오후 4시쯤 나에게만 와요. 스팸함도 확인해 보세요.
