업데이트 도우미

새 버전 코드를 내 시트에 옮기는 걸 도와드려요. 내 시트의 데이터는 그대로예요. 10분이면 충분해요. PC에서 하는 걸 추천해요.

휴대폰에서는 업데이트할 수 없어요. 구글 시트 앱에는 Apps Script 편집기와 메뉴가 없어요. 아래 버튼으로 이 페이지 주소를 복사해 두었다가 컴퓨터에서 열어 주세요. 업데이트 전에도 앱은 지금처럼 쓸 수 있어요.

1Apps Script 열기

쓰고 있는 내 시트에서 확장 프로그램 ▸ Apps Script를 눌러 주세요. 왼쪽에 파일 목록이 보여요.

2파일마다 복사해서 붙여 넣기

  1. 아래에서 복사를 눌러요.
  2. 편집기 왼쪽에서 이름이 같은 파일을 열어요.
  3. 안쪽을 눌러 Ctrl+A로 전체 선택하고 Ctrl+V로 붙여 넣은 뒤 Ctrl+S로 저장해요. (맥은 ⌘)
새 파일이면 편집기 왼쪽 + 버튼 ▸ 스크립트(또는 HTML)로 추가하고 이름을 똑같이 적어 주세요. 끝의 .gs·.html은 빼고 적으면 돼요.
appsscript.json이 안 보이면 편집기 왼쪽 ⚙️ 프로젝트 설정 ▸ "편집기에서 'appsscript.json' 매니페스트 파일 표시"를 켜 주세요.

3새 버전으로 배포

편집기 오른쪽 위 배포 ▸ 배포 관리 ▸ ✏️ ▸ 버전: 새 버전 ▸ 배포를 눌러요. 휴대폰 링크는 그대로예요.

4시트 새로고침

시트를 새로고침하면 끝이에요. 필요한 새 열이 맨 오른쪽에 추가되고 "기존 데이터는 그대로입니다" 알림이 떠요.

새 버전이 권한을 더 쓰면(예: 구글 캘린더에 일정 넣기) 시트 메뉴 ✅ 내 업무 ▸ ⚙️ 처음 설정 / 업데이트 적용을 눌러 권한 화면에서 모두 선택해 주세요. 승인 전에는 웹 화면에 "권한" 안내가 떠요.
막히면 도움말을 보거나, 복사를 처음부터 다시 해도 괜찮아요. 붙여 넣기는 몇 번을 해도 데이터에 영향이 없어요.
