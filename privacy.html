English summary

My Task Kit (web app at https://kkokio88-creator.github.io/app/) runs entirely in the user's browser. There is no operator server: Google user data travels only between the user's browser and Google APIs and is never sent to the developer or any third party.

  • drive.file — creates and reads/writes the single "내 업무관리 키트" spreadsheet the app created in the user's Drive, to store the user's tasks. The app cannot see any other file.
  • calendar.calendarlist.readonly — lists the user's calendars (name, color) so the user can choose which calendars appear in the day plan.
  • calendar.events.readonly — reads this week's events (title, time, location) from the chosen calendars to show them next to the user's tasks.
  • calendar.events.owned — when the user drags a task onto the day plan, creates an event on the user's own calendar; when the user removes it, deletes only that event. Events not created by the app are never modified.
  • openid, email — shows which Google account is signed in.

Data storage: tasks live in the user's own spreadsheet and events in the user's own Google Calendar. The browser keeps only a short-lived access token (expires in 1 hour), the spreadsheet ID and a cached view. Signing out clears them; access can be revoked at any time at https://myaccount.google.com/permissions.

Google user data is not sold, shared, transferred, used for advertising, used to train AI/ML models, or read by humans. My Task Kit's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
